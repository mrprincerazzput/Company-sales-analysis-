# Company Sales Analysis

A Python project to analyze company sales data for 12 months.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Total sales
- Average sales
- Highest and lowest sales
- Best and worst month
- Above/below average months
- Top 3 sales months
- Sales visualization using Matplotlib

## How to Run

Run the Python file:

python company_sales_analysis.py
